# Experimental Constants

## Purpose

`ExperimentalConstants` represents only the parameters considered fixed for the
historical experimental setup.

This differs from `PhysicalConstants`, which contains physical constants and
atomic properties independent of the setup. `ExperimentalConstants` describes
the historical apparatus: values such as the trapping laser wavelength and the
beam waists used in the original project.

## Usage

```python
from bec_fast_manipulation.constants import ExperimentalConstants

laser_wavelength = ExperimentalConstants.LASER_WAVELENGTH
w_h = ExperimentalConstants.HORIZONTAL_BEAM_WAIST
w_v = ExperimentalConstants.VERTICAL_BEAM_WAIST
atom_number = ExperimentalConstants.CONDENSATE_ATOM_NUMBER
omega_xi = ExperimentalConstants.INITIAL_TRAP_ANGULAR_FREQUENCY_X
omega_xf = ExperimentalConstants.FINAL_TRAP_ANGULAR_FREQUENCY_X
```

No instantiation is required.

## Laser Wavelength

| Name | Symbol | Value | Unit | Meaning |
| --- | --- | --- | --- | --- |
| `LASER_WAVELENGTH` | `lambda_L` | `1.064e-6` | m | Wavelength of the laser used in the historical setup. |

`LASER_WAVELENGTH` stores the historical laser wavelength. The laser angular
frequency `omega_L` is not included as a primitive constant.

## Beam Waists

| Name | Symbol | Value | Unit | Meaning |
| --- | --- | --- | --- | --- |
| `HORIZONTAL_BEAM_WAIST` | `wH` | `50e-6` | m | Historical horizontal beam waist. |
| `VERTICAL_BEAM_WAIST` | `wV` | `50e-6` | m | Historical vertical beam waist. |

A beam waist is the characteristic transverse size of a laser beam at its
focus. It controls the spatial curvature and confinement scale of the optical
potential generated by the beam.

In the current historical configuration,

```text
wH == wV
```

but these are two distinct model parameters. The fact that they currently have
the same value must never make the code assume that they will always be equal.
This distinction is especially important for future analysis of

```text
Omega_H(P, h)
Omega_V(P, h)
```

and for resolving the historical `wH` versus `wV` ambiguity in the modulated
potential formulas.

## Nominal Condensate Atom Number

| Name | Symbol | Value | Unit | Meaning |
| --- | --- | --- | --- | --- |
| `CONDENSATE_ATOM_NUMBER` | `N` | `100_000` | - | Nominal atom number of the prepared condensate. |

This value comes from the historical parameter:

```text
N = 1e5
```

It is an experimental parameter of the prepared condensate, not a fundamental
physical constant.

## Nominal Trap Frequencies

These six numbers define the nominal trap transformation used by the
Castin-Dum and STA parts of the historical project. They are specific to the
nominal experimental scenario, not universal physical constants.

### Initial Trap

| Axis | Angular frequency | Equivalent frequency |
| --- | --- | --- |
| x | `2*pi*500` rad/s | 500 Hz |
| y | `2*pi*600` rad/s | 600 Hz |
| z | `2*pi*700` rad/s | 700 Hz |

### Final Trap

| Axis | Angular frequency | Equivalent frequency |
| --- | --- | --- |
| x | `2*pi*5` rad/s | 5 Hz |
| y | `2*pi*5` rad/s | 5 Hz |
| z | `2*pi*60` rad/s | 60 Hz |

The initial and final angular frequencies are stored in rad/s. The historical
sources expressed the corresponding frequencies in hertz, so each angular
frequency keeps the explicit `2*pi` conversion factor in code and tests.

## Setup Constants versus Experiment Parameters

`ExperimentalConstants` contains fixed setup parameters. A given experiment
contains the particular conditions used during one run or one numerical study.

The following values must not be placed in `ExperimentalConstants`:

- laser power `P`;
- modulation period `T`;
- modulation amplitude `h`;
- crossed-beam angle `theta`;
- initial and final trapping frequencies;
- initial and final modulation heights;
- STA parameters `a` and `b`;
- final time `tf`;
- Monte-Carlo noise percentage;
- number of Monte-Carlo samples.

These values should be defined in `experiments/` or in future classes and
configurations specific to each experiment.

## Derived Quantities

Some quantities used historically are deliberately absent from
`ExperimentalConstants`.

The old code used

```text
omega_L = 2*pi*c/lambda_L
```

This is not a primitive constant: it is calculated from
`ExperimentalConstants.LASER_WAVELENGTH` and
`PhysicalConstants.SPEED_OF_LIGHT`.

The optical potential scale `U0` is also excluded. It depends on:

- the D1/D2 atomic properties;
- the laser wavelength;
- the detuning.

It must therefore be computed by the future light-matter interaction or optical
potential model. This documentation does not introduce a new implementation.

## Historical Source

The old code used in particular:

```python
lambda_L = 1.064e-6
wH = 50e-6
wV = 50e-6
omega_xi = 2 * pi * 500
omega_yi = 2 * pi * 600
omega_zi = 2 * pi * 700
omega_xf = 2 * pi * 5
omega_yf = 2 * pi * 5
omega_zf = 2 * pi * 60
N = 1e5
```

The new class centralizes these values to avoid duplicating them across
scripts. They are historical values of this project, not a claim that these
parameters are universal.
